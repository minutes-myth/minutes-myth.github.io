Privacy policy

Effective 2 October 2026

This policy covers the Minutes Myth uploader, a private tool that uploads videos to the Minutes Myth YouTube channel. It is run by the channel owner for the channel's own account only. It is not offered to the public, and no one else can sign in to it.

What the uploader accesses

When the channel owner connects the uploader to YouTube, Google asks for permission to manage the YouTube account. The uploader uses that permission only to:

  • upload the channel's own finished videos as private videos,
  • set each video's title, description, tags and language,
  • create playlists for each story and add videos to them, and
  • add a link to the next part in an earlier video's description.

It does not read comments, messages, subscribers, viewing history, analytics, or any other account's data.

What is stored, and where

The uploader runs on the channel owner's own computer. It stores the sign-in token Google issues, encrypted, plus the IDs of the videos and playlists it creates. Nothing is stored on any other server, and the uploader uses no cookies, analytics, or tracking. This website collects no personal data.

Sharing

Data received from Google is never sold, shared with third parties, used for advertising, or used to train AI models. It is sent only back to YouTube, to carry out the actions listed above.

The Minutes Myth uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be removed at any time from the Google account permissions page. Removing it stops the uploader immediately. To have the stored token and IDs deleted, email the address below; they are deleted within 7 days.
